# Swasthya Setu — Design & Requirements Workspace

This repository holds planning documents for the Swasthya Setu core. It is not an AWS deployment, SDK sample or runnable application.

## Read in this order

1. [Requirements](.kiro/specs/swasthya-setu-core/requirements.md): proposed behaviors and constraints.
2. [Design](.kiro/specs/swasthya-setu-core/design.md): architecture and implementation design.
3. [Tasks](.kiro/specs/swasthya-setu-core/tasks.md): planned work and tracking.

## Working with the documents

Cross-check task completion against executable code and verification evidence in the implementation repository. A checked planning item is not proof that a cloud resource is deployed or that a healthcare integration is validated. This repository has no dependency manifest, runtime entry point or automated test suite.

Use synthetic examples in design changes. Keep AWS credentials, account identifiers, patient records and deployment secrets outside version control. Record proposed architecture separately from verified behavior.
